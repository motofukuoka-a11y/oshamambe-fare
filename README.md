# 長万部駅 着駅精算 1.1.1

長万部駅で降車する方の運賃確認と、紙のきっぷの乗越精算を補助するWebアプリです。

公開サイト: https://motofukuoka-a11y.github.io/oshamambe-fare/

## 今回の評価と修正

前版は参考表の運賃・特急料金に整合していました。一方、乗継客の券面発駅を入力しにくいこと、原券着駅での乗継を拒否すること、条件変更時の確認操作と内訳が弱いことを修正しました。

- 券面発駅と今回の列車の乗車駅を分離。函館→森の原券で森から乗り継ぐ場合も継続乗越として計算。
- 金額式きっぷの発駅を編集可能にし、発駅・旅客区分・金額の整合を検証。
- 特急の乗車駅と原特急券の発駅・着駅を分離。今回利用する北斗の区間を含まない原特急券は自動計算を停止。
- MK払戻・払戻読取の設計をもとに、読み仮名の駅候補、手修正の保持、厳密な金額解析、入力変更後の旧結果解除を実装。
- 運賃・特急料金の差引を計算結果の数値から表示。101km以上は乗越区間を計算基準として明示。
- スマートフォンは入力→結果の順に表示。整理券・乗車券なしの運賃は駅タップで即時表示。
- メニュー／「次の精算」で旅客区分をおとなに戻し、前の精算条件を解除。
- 運賃データと画面の版を揃え、配信時に新旧ファイルを混在させないようURLへ版番号を付与。

Claudeの設計・実装レビューを行い、Codexが指摘の妥当性を規則・実装・テストで評価して修正しています。

## 対応機能

函館発普通、小樽方面発普通、東室蘭発普通、函館発特急、札幌発特急の5メニュー。駅名・ひらがな・カタカナ検索、駅タップで大きな区間名と金額を表示します。

整理券・乗車券なし、金額式きっぷ（エド券）、区間の乗越に対応。原券100km以内は全区間の差額、101km以上は乗越区間の運賃を計算します。こどもは運賃・料金をそれぞれ丸めてから差額を計算します。

北斗の普通車指定席・座席未指定の通年通常料金を使用し、特急券なし／長万部まで有効／同じ列車の特急券の乗越を選択します。新千歳空港は南千歳乗継。砂原支線、室蘭支線、小樽経由札幌、札幌市内の特例、空港加算に対応します。

## 自動計算の範囲

通常の片道・無割引の紙のきっぷ、候補駅と画面に明示する経路に限ります。原券の有効性・未精算の継続旅行であることは券面と実際の状況で確認してください。

割引、IC、定期、企画券、連絡乗車券、グリーン車、経路変更、長万部以遠、候補外の駅、原券着駅より先での列車乗継、別列車の特急券は個別確認が必要です。不明な条件から0円や推測額を出しません。決済・発券・払いもどしは行いません。JR北海道の公式アプリではありません。

## 検証・根拠

145件の自動テストで、提供された2026年3月更新表の運賃・特急合計、全料金境界、100.0/100.1/100.9/101.0km、こどもの端数、乗継、空港加算、市内特例、未入力・曖昧入力を確認します。全登録経路の原券発着駅を組み合わせた内訳一致・乗継一致も含みます。

ブラウザで、候補のタップ／上下キー・Enter、入力保持、条件変更後の旧額解除、金額式の発駅変更、旅客区分と券面額の不一致停止、特急券の発駅変更、次の精算のリセット、390px幅と1200px幅を確認しています。

運賃は2025年4月1日改定後。営業駅は2026年3月14日改正後。確認日2026年11月27日。公式の距離表・運賃表・旅客営業規則はアプリの「使い方・運賃データ」と `data.js` の `SOURCES` に掲載しています。過去のMKデータは現行資料と照合して使い、無条件には上書き適用していません。職場の参考表の原画像、個人情報、認証情報は含みません。

## 実行・更新

外部ライブラリ、APIキー、ビルドは不要です。Node.js 22以降、Python 3で確認できます。

```sh
npm test
npm start
```

ブラウザで http://127.0.0.1:4173 を開きます。ES Modulesを使うため、ファイルのダブルクリックでは実行できません。

`data.js` は駅・0.1km整数の距離・運賃表、`calculator.js` は計算、`station-picker.js` は駅検索、`fare-screen.js` は精算画面、`app.js` は画面遷移を担当します。写真・入力内容のアップロード、ブラウザへの永続保存、service workerは使用しません。

GitHub Pagesは `main` / `(root)` から配信します。運賃改定時はデータ、版番号、照合値を更新してテストし、対応する静的ファイルを配置してください。
