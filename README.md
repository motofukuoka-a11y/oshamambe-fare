# 長万部駅 着駅精算 1.4.0

長万部駅到着時の運賃・料金確認と、紙のきっぷの乗越精算を補助するアプリです。

公開サイト: https://motofukuoka-a11y.github.io/oshamambe-fare/

## 対応する精算

| 券種・割引 | 計算の扱い |
|---|---|
| 整理券・乗車券なし | 選択した乗車駅から長万部までの運賃。無割引は駅タップで即時表示。 |
| 金額式（エド券） | 券面発駅からの全区間運賃と券面金額との差額。身障第1種同行の代用券にも対応。 |
| 通常の区間乗越 | 原券100km以内は全区間の差額、101km以上は原券着駅からの別途運賃。1km未満切上げで判定。 |
| 学割 | 新規発売の片道101km以上の普通運賃を2割引。学割原券の乗越区間へ原券の割引を自動継続しない。 |
| 身障割 | 第1種本人・介護者の同行は普通運賃5割引、単独の第1種・第2種は片道101km以上。表示は各1人分。単独の短区間乗越は適用可否の確認選択が必須。 |
| ジパング | 2026年3月14日以後の新規片道101km以上、2割引・3割引。新規発売時は除外日を検証。使用開始後の原券区間外は無割引で別途計算。 |
| 大休ジパング（東日本・北海道） | 大休カードによる30％割引を全国ジパングと別制度として選択。使用開始後の原券区間外は無割引で別途計算。料金券は対応する大休割引乗車券区間内に限り、別購入時にも本人・カード決済等を確認。 |
| 北斗の特急トクだ値 | 予約区間外の無割引運賃・料金を別途計算。原券発売額を差し引かない。同じ指定列車／当日乗車券部分のみ有効を区別。 |
| 通常の特急券 | 同じ北斗・同じ座席種別の原特急券発駅から新旧料金の差額。原券101km以上でも同じ。 |

通常特急券の例：札幌→洞爺（164.9km）を長万部まで延長すると、2,950円−2,730円＝追加特急料金220円です。普通乗車券の100km／101km区分とは分けます。

乗車券と特急券の割引は別々に扱います。ジパング乗車券を選んでも、原特急券を自動でジパング券とは判定しません。料金券の割引を券面で選択します。学割・身障割を北斗の特急料金には適用しません。身体障害者割引の乗車券とジパング料金券の組合せは、別途会員・購入証・区間条件の確認を必要とします。

小児は運賃・料金をそれぞれ半額にして10円未満切捨て後、対象となる追加割引を適用します。割引後も10円未満を切り捨てます。以前のMKデータにあった切上げ処理は流用せず、現行規則に照合しています。

## 根拠と具体例

全国ジパング（会員手帳・JR乗車券購入証、会員手帳の有効期間内20回まで20％・30％）と、大休ジパング（東日本・北海道限定、大休カード決済、回数制限なし30％）を別IDで扱います。大休パス等のフリーパスは対象外です。大休料金券は対応する大休割引乗車券との組合せに限り、全国割引の購入証確認を流用しません。[JR北海道の商品案内](https://www.jrhokkaido.co.jp/CM/Otoku/007278/)から案内される全国割引の条件を、JR各社の公開資料と照合しています。

第249条第2項第1号は普通乗車券、第2号は自由席特急券・特定特急券等の区間変更です。100km以内の条件は第1号の普通乗車券に対する条件で、第2号の料金比較にその区分はありません。北斗の通常特急券の指定券変更は第252条第7・8項によります。

原乗車券・原特急券とも札幌〜洞爺で、同じ北斗で長万部まで乗り越す、おとな1人の例です。

| 原券 | 追加運賃 | 追加特急料金 | 合計 |
|---|---:|---:|---:|
| 通常券 | 1,040円 | 2,950−2,730＝220円 | 1,260円 |
| ジパング2・3割引 | 1,040円 | 区間外41.5kmの通常料金1,160円 | 2,200円 |
| 大休ジパング3割引 | 1,040円 | 区間外41.5kmの通常料金1,160円 | 2,200円 |
| 特急トクだ値 | 1,040円 | 区間外41.5kmの通常料金1,160円 | 2,200円 |

乗車券が長万部まで有効で全国ジパング／大休ジパング特急券だけ洞爺止まりなら、運賃0円・料金1,160円です。乗車券がジパングでも原特急券が通常券なら、通常券の料金差額220円を用います。

ジパングの使用開始後の変更制限は[JR東海の商品条件](https://railway.jr-central.co.jp/tickets/zipangu-club/index.html)と、同ページから参照される[お得なきっぷルール4項（区間外の別途収受）](https://railway.jr-central.co.jp/tickets/rule/index.html)に照合。[JR東日本の2026年改定FAQ Q12](https://www.jreast.co.jp/es/2026unchin-kaitei/faq.html)にも旅行開始後の変更不可・別途無割引券の購入を明記しています。トクだ値は[えきねっとの区間外乗車条件](https://www.eki-net.com/top/jrticket/guide/reserve/tokudane.html)に照合しました。[JR北海道の第249条・第252条](https://www.jrhokkaido.co.jp/network/guide/pdf/yakkan_02_07.pdf)の一般的な変更と、商品の別途乗車を混同しません。

結果の「適用規則・計算キロ」は実際に適用した規定・商品条件とリンクだけを表示します。ジパング・トクだ値の区間外を一律に第249条・第252条の変更と表示していた説明を修正しました。今回の上記具体例では計算額の変更はありません。

大休ジパングの条件は[JR東日本の割引案内](https://www.jreast.co.jp/otona/discount/)、[料金券との組合せ・公式FAQ47](https://faq.jre-ot9.jp/faq/show/47?category_id=16&site_domain=default)、[変更条件・公式FAQ43](https://faq.jre-ot9.jp/faq/show/43?category_id=15&site_domain=default)、[紙きっぷの区間外乗車](https://www.eki-net.com/top/product/tokkyu/tickets.html)に照合しています。原券の使用開始後の着駅精算として区間外を別途計算し、新たな区間に原割引率を自動継続しません。新規発売の参考計算では片道101km以上・本人・カード条件・除外日を確認します。

## スマートフォンの駅選択

幅700px以下またはタッチを主とする端末では、駅名の独自候補欄をOS標準の選択欄へ変更しました。フォーカス・blurに依存して候補が閉じる構造を避け、先頭に未選択を置きます。発駅・特急乗車駅を変えると候補を更新し、条件外となった旧着駅は「区間を確認」と表示して保持し、別駅へ勝手に変更しません。実機iOSの症状そのものは手元で再現できていないため、スマートフォン幅での選択・変更・再計算をブラウザで確認します。PCの読み仮名検索は継続します。

## 操作

函館発普通、小樽方面発普通、東室蘭発普通、函館発特急、札幌発特急の5メニューから乗車駅を選択します。券面の発着駅・金額と、該当する割引・商品の条件を入力し、「精算額を表示」で内訳まで確認します。

スマートフォンは標準の駅選択、PCの候補はひらがな・カタカナ検索、クリック、上下キー・Enterに対応。券面発駅は今回の乗車駅以前、着駅は今回の乗車駅以後かつ原券発駅より先に絞り、着駅は長万部方向順です。原券着駅で同じ旅行を継続する通常乗継にも対応します。

入力・券種・旅客区分・特急券状態を変えると旧結果を解除します。割引の確認状態や単独乗越の適用選択も、関連条件が変われば解除します。金額候補は発駅の変更へ即時追従し、手修正済み金額は保持して不一致を検証します。「次の精算」とメニューで前客の条件を解除します。

## 検証

199件の自動テスト。提供された2026年3月更新の業務表、公式幹線運賃表の全登録区分、料金境界、101km以上を含む通常特急券の発駅差額、割引別の端数、金額式、割引除外日、入力不足・不明条件からの停止を検証します。

通常券の原券区間・旅客区分7,458通り、着駅候補の受付7,451通りと拒否7,245通り、特急券の区間・旅客区分442通りの検証も維持しています。ブラウザで入力から結果表示、条件変更、確認解除、候補選択、390px幅と1200px幅の表示を確認します。Claudeのレビューは公式資料・実コード・再現結果で評価して反映しています。

## 対応範囲

画面に示す経路・候補駅と、券面・証明書・同行・日付等の適用条件を確認した有効な紙のきっぷが対象です。社割・指のみ券は今回追加していません。IC、定期、他の企画券、連絡乗車券、グリーン車、別経路、長万部以遠、原券着駅より先の未精算乗継、候補外の駅は個別確認が必要です。決済・発券・払戻は行いません。

砂原支線、室蘭支線、小樽経由札幌、札幌市内、空港加算を扱います。小樽経由札幌〜長万部は174.0km。データ内の函館起点の距離程を原券距離と取り違えないようにしています。運賃は2025年4月1日改定後、営業駅は2026年3月14日改正後、確認日は2026年11月27日です。原画像・個人情報・認証情報は含みません。JR北海道の公式アプリではありません。

## 実行・更新

外部ライブラリ・APIキー・ビルドは不要です。Node.js 22以降とPython 3で確認できます。

```sh
node --test *.test.js
python3 -m http.server 4173 --bind 127.0.0.1
```

ブラウザで http://127.0.0.1:4173 を開きます。`data.js` は駅・距離・運賃・参照元、`discounts.js` は割引条件・端数・日付、`calculator.js` は精算、`station-picker.js` は候補、`fare-screen.js` は入力・結果、`app.js` は画面遷移を担当します。入力内容のアップロード・永続保存・service workerは使用しません。

GitHub Pagesは `main` / `(root)` から配信します。改定時はデータ・版番号・照合値を更新し、テスト後に同じ版の静的ファイルを配置してください。
