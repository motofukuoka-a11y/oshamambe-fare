# 長万部駅 着駅精算

長万部駅降車時の運賃確認と、紙のきっぷの乗越精算を補助する静的Webアプリです。

公開サイト: https://motofukuoka-a11y.github.io/oshamambe-fare/

## 機能

- 函館発普通、小樽方面発普通、東室蘭発普通、函館発特急、札幌発特急の5メニュー
- 駅名・ひらがな・カタカナ検索、駅タップで大きな区間名と金額表示
- 整理券・乗車券なし、金額式きっぷ（エド券）、券面発着駅による乗越精算
- おとな・こども。運賃と特急料金をそれぞれ丸めて計算
- 原券100km以内の全区間差額／100km超の乗越区間運賃
- 北斗の普通車指定席・座席未指定。特急券なし／長万部まで有効／同じ列車の特急券を乗越
- 砂原支線、室蘭支線、小樽経由札幌、南千歳乗継の新千歳空港
- 札幌市内の運賃計算特例、大沼〜森の特例、空港加算運賃
- スマートフォン、キーボード操作、読み上げへの配慮

## 計算の範囲

通常の片道・無割引の紙の乗車券が対象です。発着駅・経路は画面の候補の範囲です。金額式は100km以内に限定し、選択した発駅を使います。特急券の乗越は同じ列車・同じ座席種別・選択した特急乗車駅からの通常の特急券に限定します。

割引、IC、定期、企画券、連絡乗車券、グリーン車、経路変更、長万部以遠、候補外の駅、発駅が異なる特急券は係員による確認が必要です。決済・発券・払いもどしは行いません。JR北海道の公式アプリではありません。

メニューに戻るとおとなにリセットします。駅一覧から選択したおとな・こどもは結果画面へ引き継ぎます。画面上の経路表示と券面を照合してください。

## データ

運賃は2025年4月1日改定後、営業駅は2026年3月14日改正後。確認日2026年11月26日。公式資料のリンクはアプリの「使い方・運賃データ」と `data.js` の `SOURCES` に掲載しています。

利用者提供の2026年3月更新表の公示運賃・料金を回帰テストに採用しています。原画像・職場の内部文書は含みません。Claudeと設計・実装レビューを行い、Codexが実装と検証を担当しました。

`data.js` に駅・距離（0.1km整数）・運賃表、`calculator.js` に計算、`app.js` に画面、`style.css` に表示を分離しています。運賃改定時はデータと照合値を更新して検証してください。service workerやローカルへの個人情報保存は使いません。更新後はブラウザを再読み込みしてください。

## ローカル実行・テスト

外部ライブラリ、APIキー、ビルド処理は不要です。Node.js 22以降とPython 3で確認できます。

```sh
npm test
npm start
```

ブラウザで http://127.0.0.1:4173 を開きます。ES Modulesを使うためファイルの直接ダブルクリックでは実行できません。

テストは参考表の金額、全運賃境界、特急料金境界、100.0/100.1km、こどもの端数、経路別特例、不正入力を確認します。
